# White Noise Generator 

> A modern web application that generates customizable white noise images to help you in your research or any CV works that involves white noise image generation.

## ✨ Description and motivation

White Noise Generator is a sleek, user-friendly web application designed to produce soothing white noise image directly in your browser.
The application offers an intuitive interface built with modern web technologies, allowing users to generate continuous white noise with just a click. Perfect person size customization of the image and image varition.


## 🎭 🧠 Motivation

The motivation behind the web app was rooted in an academic exploration of visual perception and illusion. I built the app in the context of a vision and visual illusions course, where my goal was to simulate the effectiveness of camouflage and investigate why camouflage works from a perceptual standpoint. 
The web app served as an interactive tool to model how factors such as edge detection, contrast, and background similarity influence human visual recognition. By translating theoretical concepts from vision science into a digital environment, the project allowed me to experimentally test perceptual hypotheses and observe how users respond to camouflaged stimuli in real time and which environment favors a specific camouflage pattern.
The research foundation for this project is detailed in the accompanying paper, which can be found here:
https://docs.google.com/document/d/1N-OFJWeCSvC8zbED7xcNUZWyB10mqjduOwDQ3fn5gvk/edit?usp=sharing

## 🎯 Getting Started

To run this project locally:

1. Clone the repository
```bash
git clone https://github.com/diriho/White-Noise-Generator.git
cd White-Noise-Generator
```

2. Install dependencies (once project files are added)
```bash
npm install
```

3. Start the development server (once project files are added)
```bash
Double-click on index.html
click: "Open with Live Server"
```
